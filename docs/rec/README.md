# rec/ — video explicativo

Este directorio contiene el video asciinema de **Hospital LoRaWAN Monitor** y el reproductor
que se usa en la página del proyecto.

- `hospital-lorawan.cast`: grabación original (asciicast v2).
- `hospital-lorawan.cast.js`: los eventos embebidos para el reproductor inline.
- `player.js` / `player.css`: reproductor reutilizable.

Duración: 3:10. Los fragmentos de código son reales y
corresponden a los archivos y líneas indicados en el video.
